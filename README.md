# YUI — My Personal Command Center

## What is YUI?

YUI is a personal productivity project I started because I wanted to create a place to manage different parts of my daily life. I wanted to bring my study tasks, fitness activities, notes, and other goals together instead of switching between separate tools.

I'm building YUI as a project so that I can keep improving as I learn more about programming. It started as a Python program in the terminal and gradually grew into a graphical desktop interface and a web demo.

## Reason why I made it

I'm a student, and balancing studying, fitness, personal projects, and daily tasks was difficult. I wanted to build something efficient like an personal AI to balance them,so I created YUI, your unique intelligence to help me sort them out and track them.

I also wanted to understand how a project develops from a simple idea into something people can actually try. Building YUI has gave me a chance to practice Python, work with saved data, debug errors, design an interface, and publish a project online.

My plan is to keep developing YUI over time instead of treating the first version as the finished product.

My goal is to get a new laptop prefferably a macbook or mavmini to help me with my ongoing projects.

## Features in YUI

The project right now has 7 features which includes a Assistance AI which can help us locate our work faster and runs offline for now.And the others are as follows:

- **Dashboard:** A central view of productivity information.
- **Tasks:** Organise tasks and track their completion.
- **Study:** Keep track of subjects and study goals.
- **Focus Timer:** Support focused work sessions.
- **Fitness:** Record and review workout information.
- **Notes:** Save and manage notes.
- **Assistant:** A basic assistant interface for supporting tasks and completing them.

## How I Built It

I started by building YUI in Python, using various functions and JSON files to store information such as tasks, subjects, study goals, fitness records, and notes seperatly so it won't mix up.

As the project grew, I worked on adding more features while keeping existing ones working. I then developed a graphical interface with a dark background and purple accents.In future I will also add a feature to changr the theme to ones liking

## Challenges I Faced while creating YUI

One challenging part was connecting all the different sections without losing the features I had already developed was definitely a challenge. I encountered some real headaches trying to display data correctly on the dashboard and importing Python. Eventually, I got version 1 of YUI up and running, but I had to write the code myself because my computer was a bit behind the times.

Another tough part was making the interface more user-friendly and figuring out how to publish a project that started on my personal computer. I had to get my head around Git, GitHub, dependencies, and the whole deployment process for a Python web application, which was a lot to take in.

From these experiences, I learned to break things down into smaller steps, test my changes before moving forward, and resist the urge to replace code that was already functioning well.
